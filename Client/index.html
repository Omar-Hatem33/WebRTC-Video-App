📱 Multi-Device Setup

To connect from other devices on your network:


1. Find your server IP: Check the server console for network URLs

2. Connect from other devices: Use http://[server-ip]:8080 (the server serves everything on one port — there's no separate port 3000)

3. Allow permissions: Grant camera/microphone access when prompted


⚠️ HTTPS required for calls: Browsers only allow camera/microphone access on HTTPS pages or on localhost. A plain http://[server-ip]:8080 URL will let you see peers, but calling will fail. Serve this app over HTTPS (self-signed cert, reverse proxy, or a tunnel like ngrok) for real cross-device calls.
